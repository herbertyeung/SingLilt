# 常见问题

## 程序打不开

不要只复制 EXE。便携版需要同目录的 DLL、Qt 插件、音源和识谱组件。重新解压完整 ZIP；安装版可重新运行安装程序。

## 没有声音

先检查 Windows 输出设备和音量，再检查程序中的音量、静音、混音和乐器选择。系统 MIDI 与采样音源是不同的输出方式；切换后重新播放。

## 识谱结果不准

使用清晰、端正的源图，核对音高、节奏和声部。原图上没有定位框不一定表示声音事件缺失；校正模式可以添加、删除或绑定音符。处理大图前先按页导入。

## 缺少人声分离或歌词组件

core 版不包含这两项运行时。开发构建可运行 `scripts/setup.ps1 -WithAnalysis`，再重新构建和生成 full 包。模型路径在选项中检查，识别过程不会自动联网补下载。

## 麦克风没有输入

检查 Windows 麦克风权限、默认输入设备和输入音量。练习反馈用于提示偏音和节奏，不替代专业声乐评估。

## 保存失败

选择可写目录，保留当前窗口里的未保存内容，再重试。不要把自动恢复文件当成正式工程的唯一副本。

提交 issue 时附上程序版本、操作步骤和错误信息。不要上传 API 密钥、私人歌曲或录音。
