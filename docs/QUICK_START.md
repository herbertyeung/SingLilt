# SingLilt 快速入门

## 第一次练唱

1. 双击`SingLilt.exe`，先播放内置练习。需要课程时，从练习菜单进入唱歌课堂或听力练耳。
2. 歌曲练唱默认展示练习模式。点击谱面定位/试听，用播放、节拍器、速度、移调和循环练一句。A音色用于第一遍，B音色用于反复第二遍，不是循环端点。
3. 需要核对材料时切换“校正”。右侧修改音符、歌词或反复；“下一个待核对音”定位机器不确定的音。应用修改后可撤销/重做；未应用草稿切换时会询问。
4. “文件 → 保存/另存为”保存JPP，文件身份和未保存标记持续显示。最近工程可继续练习。

## 我的歌曲

图片/简谱用“文件 → 导入图片/乐谱”；音频用“文件 → 导入音频”。原音可以先播放。分析结果是需要校正的候选，不是原曲总谱或歌词真值。开始分析前会按此次选择检查本地模型/运行时；缺件不会悄悄转成混合音轨分析。

当前这一批的课堂评分仍针对课程目录中的材料；把主窗口自己的歌直接送课堂评分属于后续切片。不要把进入默认课堂当作当前歌曲已评分。

## 基础课堂与练耳

先听示范，再跟唱/独立唱。反馈保留音准、节奏和有效覆盖；噪声或沉默不会冒充可靠结果。蓝色目标/橙色实际曲线和逐音结果可辅助定位复练。钢琴示范不是人声示范。

学习记录无法写入时，会持续显示待保存数量和“重试保存记录”。修复目录/文件后重试；关闭前会确认是否丢弃仍在内存中的待保存记录。记录摘要不包含录音；录音由用户主动保存。

## 设置和声音

- 播放区的速度/移调/音量作用于当前练习；原音/人声/伴奏轨与合成谱使用各自既有控制。原音不支持此处的合成移调。
- 选项中的本机默认值不覆盖已打开谱；当前谱属性随JPP保存。
- 分离后频段增强仅在先分离人声时启用；应用AI配置不启动识别，密钥不写入配置或工程。
- 没有声音：检查当前声音来源、静音/声部开关、应用音量、系统输出设备；选项的组件状态明确显示音源是否存在。可主动选择系统MIDI，不会无提示冒用另一个音源。

## 导出练习WAV

文件菜单导出的是合成谱与已确认编配，不是原音或未确认候选。按当前速度、移调、混音和节拍器选择实际练习时间轴区间。每段音乐最长600秒（10分钟），另加1.5秒释放尾音；短谱默认完整。导出完成显示范围、长度和整曲/片段身份。

## 发布包

核心包包含练唱、课程、真实钢琴音源和工程操作；本地分离/歌词分析组件在完整包中。核心包缺少分析组件时，基础练唱不受影响，分析前明确提示缺项。`package-manifest.json`记录版本、文件大小和SHA256；ZIP另有整体校验文件。

便携包不是单文件EXE，请整体搬移。JPP则是自包含工程，可独立搬移并离线重开。详细格式见[工程文件说明](PROJECT_FORMAT.md)。
