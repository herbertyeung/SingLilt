# 五线谱练习与校正

## 导入材料

可导入 MusicXML、单页图片或多页扫描图。导入图片后先检查页序和拆页结果，再等待识谱候选；接受候选后才替换当前工程。需要先保存的旧工程会提示处理。

默认图片识别使用本地 CrispEmbed/Transcoda CPU 运行时，core 包已包含所需组件。识别时不下载模型，也不上传图片。

自动识谱可能漏音或误判节奏，尤其是复杂声部、连音和不清晰的符头。接受结果前核对速度、拍号、音高和各声部；警告仍然保留在工程中。

## 原图与声音

原图保留输入页面的像素。声音来自识别或导入的音乐事件，定位框把这些事件绑定到原图位置。没有定位框的音符仍可能有声音；不要只凭框的数量判断是否漏音。

播放时，绿色框表示当前发声事件；暂停后保留当前定位。点音和翻页使用同一份时间轴。多页材料按各页的共同音乐时间连续播放，可以手动翻页或启用自动翻页。

MusicXML 导入可以生成谱面视图；生成排版不等于原扫描图的逐像素复刻。原图、谱面排版和音乐数据是分别保存的材料。

## 练习

- 练习模式下点击音符可以定位、查看属性或试听。
- 调整速度、移调、音量和声部混音，再设置循环片段。
- 主谱表与其他谱表可选择不同的 GM 乐器；更换乐器不改变音乐时序。
- 若速度需要确认，先核对 BPM，再开始整曲播放或 WAV 导出。

单音导唱线用于歌词和练唱定位；完整声部保存同时发声的和弦与其他声部。完整五线谱播放不会把导唱线重复叠加一次。

## 校正音符

切换到校正模式，再选择原图上的音符。侧栏显示音高、小节、拍内起点、时值、谱表和声部。先试听或预览，再应用；取消不会写入工程。

右键可以添加漏音、添加同拍音符或删除所选音符。没有框但音乐事件已经存在时，应绑定现有音符的位置，而不是重复添加。

拖动行为由两个选项控制：

- **拖动升降音阶**：上下拖动调整音高，松开后试听。
- **左右调整起点**：左右拖动调整小节内的起点；关闭后只改定位。

新增音符的拍位建议来自同谱行、同小节的可靠音符。缺少可靠依据时需要手动填写起点，程序不会按整页宽度编造节奏。原图上的校正层不改写源图像素。

音乐编辑支持撤销、重做和独立自动保留。切换音符或模式时，未应用的草稿会要求应用、放弃或取消切换。

## 保存和恢复

保存为 JPP 后，源页、完整声部、时间轴、定位及练习设置一起进入工程。重新打开不需要原 MusicXML 文件或图片路径。

自动保留文件与正式工程分开；恢复后仍需另存正式工程。工程字段、版本兼容和资源限制见 [PROJECT_FORMAT.md](PROJECT_FORMAT.md)。

## 开发构建

```powershell
pwsh -NoProfile -File scripts/setup-native-staff-omr.ps1
pwsh -NoProfile -File scripts/build.ps1 -Configuration Release
```

模型与运行时的版本、来源和哈希固定在设置脚本中。公开 MusicXML 示例位于 `assets/staff-samples`；私人歌曲图像不进入源码仓库或发行包。
