# SingLilt 窗口菜单和选项

## 启动

开发构建入口固定为`build/bin/Release/SingLilt.exe`；便携发布包入口为程序目录中的`SingLilt.exe`。
直接双击EXE，整体保留同目录DLL、platforms和assets；完整分析包还包含tools和models。
生成仍复用根目录的build，不创建另一套构建树。Debug和各验证目录不是日常入口。
旧版本备份位于build/backups/executables；原来的两个CMD启动脚本已移除。
帮助菜单只保留「关于」：显示程序版本、唱歌教学与练习功能介绍、作者 Herbert Yeung 和 Copyright。不展示程序入口路径，也不放「打开程序目录」。音频导入统一从文件菜单进入。

## 功能入口

- 文件：新建工程、打开工程、导入图片/乐谱、导入音频、粘贴图片、最近工程、保存、另存为、导出合成练习WAV、退出。
- 编辑：撤销、重做、歌词、反复/一二房子、适合宽度。材料撤销与本机偏好分开。
- 练习：练习/校正模式、唱歌课堂、听力练耳、生成伴奏和练习示例。新建空工程自动进入校正模式。
- AI：明确启动联网识谱、打开AI选项。音频分析/歌词识别从文件菜单的音频导入窗口进入。
- 选项：统一设置窗口。
- 帮助：关于（程序介绍、版本、作者和版权）。

合成练习WAV导出复用当前混音/移调/速度和伴奏；每次导出最多600秒（10分钟），菜单明确标注。
它不是原音人声分离结果的整曲导出。导出在工作线程执行，源乐谱保持不变。

## 两类设置

1. **应用偏好**：常规、音频默认值、麦克风/练习和AI页面；保存到本机QSettings配置。
2. **当前乐谱/练习**：只改变当前内容和播放状态。当前谱参数、音色和混音随JPP保存；
   当前移调/速度是播放状态。课程本身仍由外部JSON管理，不从设置窗口改写课程文件。

音频默认值用于新生成的谱面，已有JPP的设置不被默认值覆盖。
主谱的**节拍器、A音色、B音色**是高频操作，保留在播放栏；选项从同一当前状态读取。
快速改音色会修改当前谱，按普通未保存流程保存，不另造一份音色状态。

应用/确定会验证后提交；取消只放弃尚未应用的编辑。
已点过「应用」的修改不会因为之后点「取消」而回退。
未编辑的高精度BPM/混音数值不会因界面小数位舍入而被改写。
错误路径、接口或谱面参数留在设置窗口供修正，原谱不被错误输入替换。

## 界面主题

「选项 → 常规 → 界面主题」提供「跟随系统」「浅色」「深色」。默认跟随系统。
点击「应用」或「确定」后立即切换并保存，重新启动仍使用该选择。
跟随系统会响应 Windows 应用颜色模式的变化；手动选浅色或深色则保持不变。
取消只丢弃未应用的选择，已经应用的主题不会回退。

主题只改变窗口、菜单、控件、音高曲线和乐谱视图周围的颜色。
乐谱纸面、原始图片以及 PNG/WAV/JPP 导出内容不会因主题改变。

## AI

接口地址、模型、超时、本地歌词模型、歌词语言、分离/识别默认选项集中在AI页。
保存AI选项**只更新配置，不发送请求**；从AI菜单明确选择识谱才创建任务。
已发出的任务继续使用发起时的配置快照，修改默认值不重写其请求。
API密钥使用密码输入框，仅本次进程保留，不写入QSettings、JPP或日志。
程序启动时仍支持原有OPENAI_API_KEY环境变量。

音频导入对话框保留本次分析的时段、BPM候选和歌词输入；模型/语言等偏好由选项提供。
保存配置不是识别成功，不替换当前谱面；既有结果预览/确认流程保持不变。

## 麦克风和课堂

课堂也有「选项」菜单，包含默认设备、难度、容差、速度、提示方式和延迟。
选择默认设备跟随系统当前输入；保存的设备离线时明确标出，不冒充已连接。
录音、校准、示范或首次音源加载期间不应用新练习设置；停止后再操作。
噪声校准、刷新设备、回放与保存录音从课堂的练习菜单进入。
容差/设备校准仍需结合真实歌声，程序未把这些偏好值当作准确率证明。
