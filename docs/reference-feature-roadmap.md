# 参考功能补齐：分阶段实施与验收

状态：阶段 1 已完成实现、测试、独立代码复审及回滚校验；阶段 2 的已确认范围已实现并通过验证；阶段 3–5 是后续方案。

## 阶段 1：现有模型内的节奏输入补齐
- 六十四分及附点：30/45 ticks，四条减时线，输入/选中回显、撤销、保存重开与播放时值。
- 整小节休止：只替换活动声部的目标时间区间，不压缩之后的书写时间；支持跨界长音切分。
- 复用 NumberedEditing、现有提交/撤销、渲染和存储，不引入新文件格式。
- 现有固定小节/位图容量仍适用；过密输入或极端拍号导致版面超限时，候选编辑必须原子失败。

## 阶段 2：曲级小节和统一演奏时间
本轮覆盖局部拍号、速度、调号、多声部反复及重复房子；D.S./D.C./Coda 留待后续。
- 领域：新增 NumberedScoreStructure / PerformedScoreMap，保存曲级小节属性、稳定小节标识及公共遍历片段。
- 时间：扩展 Timeline 的分段 tick↔seconds 映射；PlaybackEngine、WAV、定位、节拍器与循环共同消费同一映射，不能各算一份全局 BPM。
- 应用：NumberedCompositionEditing 统一处理插删小节后的事件迁移和引用修复；旧 UI 入口继续校验，不提前解禁。
- 存储：显式升级创作工程版本，验证旧文件迁移与旧读取器拒绝新格式。
- 验收：多声部不同节奏密度、变速边界长音、暂停/定位/循环、反复房子遍数、非法循环预算、GUI 与 WAV 总时长一致。

## 阶段 3：稳定音符锚点、文本和跨音符结构
- 为创作音符建立真正唯一且持久的标识；不直接把当前默认可重复的 Note.id 当可靠锚点。
- 使用带类型的跨度/标注：和弦、分段和标题、表情文字、括号、连奏线、连音组、倚音；编辑操作维护端点。
- 区分同音高延音线与跨音高连奏线；连音组保留比例，倚音显式规定占时，不塞零时值普通音符。
- 渲染、命中和文档数据分离；纯文字标注不虚构声音效果。
- 验收：端点删除/移动、跨小节/跨页范围、撤销重做、保存兼容、Zoom 命中；有声音语义的项目校验真实事件计划。

## 阶段 4：连续演奏记号
- 渐强/渐弱、踏板、滑音/装饰音、保持音、延长和换气。
- 新增明确的控制器/包络事件和统一时间语义，而不是仅画符号。
- 当前共用音色路线下，踏板作用范围必须清楚；停止、定位、循环和导出都要恢复正确控制器状态。
- 验收：事件/控制器时间、循环与停止清理、跨声部同步、离线 WAV；硬件听感不以静态字段代替。

## 阶段 5：分段声部范围、分页与导出
- 当前段/整乐段范围的声部操作需要段落模型，不复用像素行号。
- 创作分页单独建模，不借用原谱 staffPages 资源角色；版面参数、页面布局和持久化版本一起实现。
- PDF/分页图片从相同布局导出，检查全部页，不用只裁切当前可见区域。
- 验收：跨页连线/歌词/选中/播放跟随、原子保存、旧版拒绝、导出页数和裁切、最小窗口与高 DPI。

## 责任边界与阶段门槛
UI → 应用编辑事务 → 领域模型；存储、布局和播放适配器消费领域数据。复用现有撤销 Command 和 Qt 回调，不新增无需求的通用框架。

每阶段：先写用例并验证已有实现的缺口 → 最小实现 → 核心/存储/GUI/声音语义测试 → Release 构建 → 图片检查 → 独立 Subagent CR → 修复审查项 → 回滚验证。测试未通过或只有按钮时，不把阶段标为完成。

独立架构 CR 已确认的关键限制：全局 BPM 的三处分散换算、composition 禁止局部结构、Note.id 非唯一、踏板缺控制器接口、schema 7 不接受创作分页。以上方案必须先解决这些边界。


## 阶段 1 实际验收（2026-11-07）
- 六十四分工具及附点 30↔45 已接入原有编辑/播放/保存路径，四条减时线有像素级检查。
- 整小节休止提供目标小节对话框，可指定跨小节长音中的内部小节。取消不改文档/历史；完成后选中生成的休止符。
- 原起音的左片段保留其标记，右侧重新起音片段清除歌词和起音标记；保留到原后继的有效延音连接。范围内最后一个力度标记转移到休止，保留之后的继承力度。
- 替换不会压缩之后的书写时间，未被切分的区间外音符与其他声部保持。切分长音属于重新记谱/起音，不宣称其采样尾音与原来完全相同。
- 初始失败基线已记录；独立子代理发现的附点取消回显、长音内部小节可达性及额外时值高亮问题，均补用例、验证失败后修复。
- 当前节奏专项 28/28、核心测试 28/28；原有 90 项编辑器检查及五组其他诊断通过。
- 48 kHz 离线 WAV：30+45+30 ticks、120 BPM 对应 5250 musicFrames；整小节休止多声部样例对应 120000 musicFrames。两份输出均无削波。
- 容量边界保留：超密整小节六十四分或 64/1 等超宽休止画法会在候选校验阶段拒绝，不改文档、光标或撤销记录。

## 阶段 2 实现范围（2026-11-07）
- 「小节」工具页可为指定小节设置或清除拍号、BPM、调号；空白属性继承前一小节，第一小节继承曲级值。变拍重新划分小节，不改已有音符的书写时值。
- 反复适用于全体声部。支持互不重叠的反复段（2–8 遍），可指定第一房子起点；第二遍起跳过第一房子，最后进入后续第二房子。插删小节保留稳定引用；删除被反复引用的小节须先修改反复。
- 实时播放和 WAV 共用演奏 tick 与秒的分段映射。局部调号决定起音音高；连续长音穿越变速、转调时保持原音高和起音。谱面同步标注小节属性及反复/房子。
- 带曲级结构的工程写入 schema 8；旧版工程仍可读，未使用曲级结构的创作工程保留 schema 7。旧读取器明确拒绝 schema 8。
- 循环复用现有 UI 轮询机制，端点使用演奏 tick，不承诺采样级循环精度。

- Windows Release 验证：核心 29/29、节奏专项 42/42（包括小节编辑后即时更新演奏时长），编辑、审校、工程容器、五线谱录入、WAV 回归均通过。双声部反复样例演奏 16 秒；48 kHz 导出在 0.25× / 1× / 2× 下分别为 3,072,000 / 768,000 / 384,000 音乐帧。新增跨变速点的片段裁剪与音频连续性检查。

### 阶段 2 后续：反复编辑、实时播放与草稿恢复
- 「反复与房子」可点击小节并用 Shift 选连续范围，保留数字输入；从反复段内打开会带出已有配置，更改起点会更新原反复而不是叠加。用独立的「移除反复」提交一次可撤销操作。工程格式与现有反复遍历规则不变。
- 简谱编辑提交后延迟 750 ms 写入单独的本地草稿。关闭或切换工程时会写入待保存的变更；正式保存成功后清理当前草稿。通过「文件 → 恢复最近的简谱草稿」打开未保存副本，手动保存的源工程不受影响。草稿有窗口级独占锁，防止另一实例覆盖；恢复会跳过活跃或损坏的文件。
- 实时验收使用同一份双声部、局部变速与反复样例，检查播放越过变速点、暂停、滑杆定位至第二遍和 A/B 循环；验证的是输出后端和播放状态，不是扬声器声学测量。
- 下一步仍是稳定音符锚点与文本、跨音符编辑；本轮不改变跳转记号、创作分页或采样级循环调度。
