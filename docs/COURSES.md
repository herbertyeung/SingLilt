# 文件化唱歌课程

## 使用

直接双击 `build/bin/Release/SingLilt.exe`，从「练习 → 唱歌课堂」进入。

课堂从程序旁的 `assets/lessons/index.json` 加载课程。开发源文件在项目根目录的
`assets/lessons/`；构建后的运行副本在 `build/bin/Release/assets/lessons/`。
编辑开发源后重新构建会复制课程；编辑运行副本后点「重新加载课程」即可看到变化，
不必重新编译 C++。也可点「打开课程目录」选择自己的独立目录。

课程、教学说明和练习谱是外部数据，不嵌入 exe。听力出题、播放和判读算法由程序实现。
八课分别训练音阶、长音、模唱、节拍、音程、乐句、歌词和完整练习歌。
第八课的「晨风练习歌」是新编短练习，不是对现有歌曲的扒谱。

## 目录文件

`index.json` 决定展示顺序：

```json
{
  "schema": 1,
  "lessons": ["01-scales.json", "02-long-tones.json"]
}
```

课程路径相对所选目录，不能指向外部文件；最多128课、每文件1MiB，id不可重复。
所有文件先验证，成功后才替换当前目录；坏文件显示路径与原因，不丢弃已加载的课程。

## 可复制的最小课程

保存为 `09-my-lesson.json`，并把文件名加到 `index.json` 的 `lessons` 中：

```json
{
  "schema": 1,
  "id": 9,
  "title": "第九课 · 我的长音练习",
  "goal": "听清目标音，在准备拍后唱稳两拍。",
  "steps": "1. 先听示范。\n2. 用 u 模唱。\n3. 看反馈，再重试。",
  "selfCheck": "是否唱满两拍？是否在休止处停止？",
  "score": {
    "tonic": 0,
    "bpm": 80,
    "beatsPerBar": 4,
    "beatUnit": 4,
    "versePrograms": [0],
    "notes": [
      {"degree": 1, "durationTicks": 960, "lyric": "u"},
      {"degree": 0, "durationTicks": 960},
      {"degree": 2, "durationTicks": 960, "lyric": "u"},
      {"degree": 0, "durationTicks": 960}
    ]
  },
  "practice": {
    "centsTolerance": 50,
    "timingToleranceMs": 180,
    "earExercises": ["single_echo", "direction"]
  }
}
```

标题、目标、步骤、自查可以是字符串，也可以是 `{"zh_CN":"中文","en_US":"English"}`。
未匹配的语言依次取英文、中文。它们按普通文字展示，不执行文字中的命令。

音符字段：`degree` 为0休止、1–7音级；480 ticks为一拍四分音符。
`octave` 默认0，`accidental` 默认0，`tieToNext` 默认false；
`measure` 可省略，程序按累计拍数生成；不必填写图片坐标。
`score` 也支持现有乐谱的反复、延音和歌词字段。
每课最多512源音符，基础时间轴最长110秒；慢速导致超过110秒时请选择乐句。

题型配置：`direction`高低、`same`同异、`degree`主音参照唱名、
`interval`自然大调音程、`rhythm`节奏选择、`single_echo`单音模唱、`phrase_echo`短句模唱。
容差范围10–100音分，起唱/收音容差50–500ms。数值是练习参数，不是专业声乐评级标准。

## 练唱与判读

1. 选择课程、音域移调、速度与整课/乐句。点击谱面选择乐句，点「听示范」。
2. 选麦克风；可在安静两秒时校准噪声门限。
3. 点「麦克风练唱」，看四拍准备提示；显示「开始唱」后进入。
4. 保留约一秒收音观察尾段后，查看目标/实测曲线、逐音偏差、有效覆盖与起唱/收音偏差。
5. 点击错误音的反馈行选择对应乐句，重新听、重新唱。

独立唱只有节拍器；跟唱和伴奏模式可能被扬声器串音干扰，使用耳机会减少这种影响。
耳训练先听后答，答前隐藏答案谱和实时目标提示；重听次数与一次提交的对错分开记录。
「薄弱项复练」按最近50次可靠听力作答的错误率，在当前课程允许的题型中选题。
第一遍和重听后的表现可通过记录中的「听示范次数」区分。

检测器保留连续频率，不先四舍五入成音符；分析范围约65–1500Hz。
低置信度、噪声与削波显示「检测不确定」，没有声音显示「漏唱」；八度错误单独报告。
评分按整段目标时长计算，漏唱不能通过只唱少数正确音得到满分。
有效检测覆盖低于50%时不显示可靠总分。系统检测音高/时序，不识别歌词内容，
不评判呼吸方法、音色或完整发声技巧。

延迟补偿为手动输入，并非自动测得的设备延迟。默认音准容差50音分，
节奏容差180ms；最终教学参数仍需真实歌声和不同设备验证。
钢琴示范是音高提示，不是合成人声。

## 录音和记录

录音在本次课堂内存中保留；回放时生成临时WAV，关窗删除。
只有主动「保存录音」才保存到学生选择的位置；不上传音频。
开始新录音或噪声校准会替换当前录音，请先保存需要保留的录音。
学习摘要保存在 Qt 的本地应用数据目录，Windows 下为 `%LOCALAPPDATA%/SingLilt/SingLilt/practice-history.json`（最多500条），旧版本的记录会在首次正常启动时导入，
不含录音。写入使用原子替换和文件锁，损坏的原文件不会被覆盖。
取消练习不评分、不增加学习记录；麦克风中断/溢出停止本次判读。

## 验证

已有核心测试中加入连续音高、判读和听辨生成三组，仍使用一个build目录和一个核心测试工程。
专项诊断 `--classroom-check --report <新目录/report.json>` 验证课程加载、编辑热加载、
保存重开、答案隐藏、真实播放、提交、语言切换与记录；
加 `--microphone-check` 才验证真实设备采集、录音、取消、反馈和回放。
诊断只写报告所在的新目录，不改学生学习记录。
这些设备与合成信号检查不等于真人歌唱准确率测试。

## 点击音符试听与均匀力度（0.9.1）

主谱暂停时点击音符会短音试听，仍保留原来的选中和定位；播放中点击仍按原逻辑定位。
旋律静音时点击可独立试听而不改变静音设置。课堂点谱同时选择乐句并试听；
听力题只有提交后显示的答案谱才允许点音试听。休止取消试听，快速点击替换前音，
停止、换谱和关窗会清理试听声部。录音或噪声校准时点击不发额外提示音。

试听复用当前窗口音源，使用独立通道3，默认650ms，不开始整首播放。
第一次可能需要准备钢琴库，后续复用已打开的音源；进入课堂前主窗口释放设备，
避免系统MIDI占用冲突。保持主谱和定位，返回后再播放会重新打开音源。

八课外部文件显式使用 `score.accentBeats=false`，听力示范也采用均匀力度。
原有导入歌曲的重拍设置未改，主谱仍可选择「重拍层次」。
相同力度不等于所有钢琴音等响：Salamander的C4与D4在本次同音长、同音量测量中
第一秒PCM RMS仍相差约4.464dB；重拍96对普通88时约6.699dB。
这是特定采样的RMS测量，不是所有音域、音源的听觉响度结论，也没有逐音强行归一化。

## 统一选项与快捷控制（0.10.0）

全局偏好通过主窗口或课堂的「选项」菜单编辑。麦克风、难度、容差、延迟、音源等
设置集中在选项窗口，课堂保留听示范、录音、提交与回放这些操作。
主谱播放栏保留常用的节拍器和A/B音色快捷切换；它们与当前乐谱/选项共用状态。
音符和歌词编辑不是全局偏好，仍在谱面编辑区完成。
